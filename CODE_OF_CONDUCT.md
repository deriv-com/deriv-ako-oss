# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, welcome newcomers, and keep discussion about the work. Harassment and personal attacks aren't tolerated in issues, pull requests or any other project space.

## Reporting

Report unacceptable behaviour to [security@deriv.com](mailto:security@deriv.com) with "Deriv AKO conduct" in the subject. Reports are handled confidentially by the maintainers, who may warn, temporarily ban or permanently ban anyone who breaks this code, as set out in the Contributor Covenant's enforcement guidelines.
